## 🚀 快速部署（3 步搞定）

### 方法一：使用启动脚本（推荐）

1. **安装 Python**
   - 下载：https://www.python.org/downloads/
   - 版本：3.8 或更高
   - ⚠️ 安装时勾选 "Add Python to PATH"

2. **双击运行 `环境配置.bat`**
   - 自动安装所有依赖包
   - 创建必要目录

3. **双击运行 `一键启动.bat`**
   - 自动启动系统
   - 浏览器打开：http://localhost:8501

### 方法二：手动部署

```bash
# 1. 进入项目目录
cd retail_analytics

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动系统
streamlit run app.py
```

## ⚙️ 配置说明

### MiMo API 配置（可选）

编辑 `config/settings.py`，填写 API 信息：

```python
MIMO_CONFIG = {
    "api_key": "your_api_key_here",
    "base_url": "your_base_url_here",
    "model": "your_model_name_here",
}
```

如不配置，系统将使用模拟回答功能。

### 修改端口

启动时可指定端口：

```bash
streamlit run app.py --server.port 8502
```

## 🔧 常见问题

### 1. Python 未找到

**错误**：'python' is not recognized as an internal or external command

**解决**：
- 重新安装 Python，勾选 "Add Python to PATH"
- 或使用完整路径：C:\Python39\python.exe

### 2. 端口被占用

**错误**：Port 8501 is already in use

**解决**：
```bash
# 修改端口
streamlit run app.py --server.port 8502
```

### 3. 依赖安装失败

**错误**：pip install 失败

**解决**：
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. PowerShell 执行策略错误

**错误**：无法加载文件，因为在此系统上禁止运行脚本

**解决**：
- 使用 CMD 运行批处理文件
- 或右键"以管理员身份运行"

### 5. 数据库锁定

**错误**：database is locked

**解决**：
- 关闭其他访问数据库的程序
- 删除 `data/retail_analytics.db`，重新生成
