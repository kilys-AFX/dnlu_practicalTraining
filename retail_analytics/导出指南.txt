【导出步骤（3种方法）】

════════════════════════════════════════════════════════
方法一：使用打包脚本（最简单，推荐）
════════════════════════════════════════════════════════

1. 双击运行 "打包项目.bat"
2. 等待自动打包完成
3. 选择是否创建 ZIP 压缩包（推荐选 Y）
4. 获得完整导出包：export_package/retail_analytics.zip

════════════════════════════════════════════════════════
方法二：手动复制必需文件
════════════════════════════════════════════════════════

1. 创建新文件夹，例如：retail_analytics_export
2. 复制以下文件和目录：

   必需文件：
   ✓ app.py
   ✓ requirements.txt
   ✓ README.md
   ✓ 部署说明.md
   ✓ 快速部署指南.md
   ✓ 一键启动.bat
   ✓ 环境配置.bat
   ✓ start.py

   必需目录（包含内容）：
   ✓ config/
   ✓ data/          (不含 .db 文件)
   ✓ pages/
   ✓ utils/
   ✓ models/
   ✓ assets/
   ✓ deploy/

3. 压缩成 ZIP 文件

════════════════════════════════════════════════════════
方法三：使用 Git（如果项目在 Git 仓库中）
════════════════════════════════════════════════════════

git clone <repository_url>
cd retail_analytics
pip install -r requirements.txt

【在目标电脑部署（3步搞定）】

════════════════════════════════════════════════════════
第 1 步：安装 Python
════════════════════════════════════════════════════════

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.8 或更高版本
3. 安装时务必勾选 "Add Python to PATH"
4. 验证：打开 CMD，输入 python --version

════════════════════════════════════════════════════════
第 2 步：配置环境
════════════════════════════════════════════════════════

Windows 用户：
1. 解压项目到任意目录（建议路径不含中文和空格）
2. 双击运行 "环境配置.bat"
3. 等待依赖安装完成（约 2-5 分钟）

Mac/Linux 用户：
1. 解压项目到任意目录
2. 打开终端，进入项目目录
3. 运行：bash start_mac_linux.sh

════════════════════════════════════════════════════════
第 3 步：启动系统
════════════════════════════════════════════════════════

Windows 用户：
- 双击运行 "一键启动.bat"

【常见问题】

Q1: Python 安装后提示"不是内部或外部命令"
A: 重新安装 Python，勾选 "Add Python to PATH"，或重启电脑

Q2: 依赖安装失败
A: 右键"环境配置.bat"，选择"以管理员身份运行"
   或手动执行：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

Q3: 端口被占用
A: 编辑"一键启动.bat"，将 --server.port 8501 改为 --server.port 8502

Q4: 启动后无法访问
A: 检查防火墙设置，或手动打开浏览器访问 http://localhost:8501
