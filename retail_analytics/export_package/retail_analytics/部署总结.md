## 🚀 完整部署流程

### 在源电脑（当前电脑）

#### 方法一：使用打包脚本（推荐）

1. 双击运行 `打包项目.bat`
2. 等待自动打包完成
3. 选择是否创建 ZIP 压缩包
4. 获得 `export_package/retail_analytics.zip`

#### 方法二：手动打包

1. 创建新文件夹 `retail_analytics_export`
2. 复制以下文件和目录：
   - ✅ `app.py`
   - ✅ `requirements.txt`
   - ✅ `README.md`
   - ✅ `部署说明.md`
   - ✅ `快速部署指南.md`
   - ✅ `一键启动.bat`
   - ✅ `环境配置.bat`
   - ✅ `start.py`
   - ✅ `verify_installation.py`
   - ✅ `config/` 目录
   - ✅ `data/` 目录（不含 `.db` 文件）
   - ✅ `pages/` 目录
   - ✅ `utils/` 目录
   - ✅ `models/` 目录
   - ✅ `assets/` 目录
   - ✅ `deploy/` 目录
3. 压缩成 ZIP 文件

### 在目标电脑

#### 步骤 1：安装 Python

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.8 或更高版本
3. **重要**：安装时勾选 "Add Python to PATH"
4. 验证：打开 CMD，输入 `python --version`

#### 步骤 2：解压项目

1. 将 ZIP 文件复制到目标电脑
2. 解压到任意目录（建议路径不含中文和空格）
3. 例如：`C:\retail_analytics\`

#### 步骤 3：配置环境

**Windows 用户**：
- 双击运行 `环境配置.bat`
- 等待依赖安装完成（约 2-5 分钟）

**Mac/Linux 用户**：
```bash
cd retail_analytics
python start.py
```

#### 步骤 4：启动系统

**Windows 用户**：
- 双击运行 `一键启动.bat`

**Mac/Linux 用户**：
```bash
cd retail_analytics
python start.py
```

或手动启动：
```bash
streamlit run app.py
```

#### 步骤 5：访问系统

1. 浏览器打开：http://localhost:8501
2. 使用默认账号登录：
   - 账号：`admin`
   - 密码：`admin123`
3. 在左侧边栏点击「🔄 生成模拟数据」

## 🔧 常见问题解决

### 问题 1：Python 安装后无法识别

**现象**：CMD 输入 `python` 提示"不是内部或外部命令"

**原因**：Python 未添加到 PATH

**解决**：
1. 重新安装 Python，勾选 "Add Python to PATH"
2. 或手动添加 Python 安装目录到环境变量
3. 重启电脑

### 问题 2：依赖安装失败

**现象**：运行 `环境配置.bat` 时报错

**原因**：网络问题或权限不足

**解决**：
1. 右键"环境配置.bat"，选择"以管理员身份运行"
2. 使用国内镜像源：
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
3. 检查网络连接

### 问题 3：端口被占用

**现象**：启动时报错 "Port 8501 is already in use"

**原因**：端口 8501 已被其他程序占用

**解决**：
1. 修改端口：编辑 `一键启动.bat`，将 `--server.port 8501` 改为 `--server.port 8502`
2. 或关闭占用端口的程序

### 问题 4：浏览器未自动打开

**现象**：系统已启动，但浏览器未打开

**原因**：浏览器设置或权限问题

**解决**：
1. 手动打开浏览器
2. 访问 http://localhost:8501

### 问题 5：数据库错误

**现象**：提示 "database is locked" 或类似错误

**原因**：数据库文件被占用或损坏

**解决**：
1. 关闭系统
2. 删除 `data/retail_analytics.db`
3. 重新启动系统
