# 快速部署指南

## 🚀 3 步快速开始

### 第 1 步：安装 Python

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.8 或更高版本
3. 安装时**务必勾选** "Add Python to PATH"
4. 验证安装：打开 CMD，输入 `python --version`

### 第 2 步：配置环境

1. 解压项目包到任意目录（建议路径不含中文和空格）
2. 双击运行 `环境配置.bat`
3. 等待自动安装依赖（约 2-5 分钟）

### 第 3 步：启动系统

1. 双击运行 `一键启动.bat`
2. 等待系统启动（首次启动约 1-2 分钟）
3. 浏览器自动打开 http://localhost:8501
4. 使用默认账号登录：
   - 账号：`admin`
   - 密码：`admin123`

## 🔧 常见问题

### Q1: Python 安装后提示"不是内部或外部命令"

**解决**：重新安装 Python，勾选 "Add Python to PATH"，或重启电脑。

### Q2: 依赖安装失败

**解决**：
1. 确保网络连接正常
2. 右键"环境配置.bat"，选择"以管理员身份运行"
3. 如果仍失败，手动执行：
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

### Q3: 启动后无法访问

**解决**：
1. 检查端口是否被占用：`netstat -ano | findstr 8501`
2. 修改端口：编辑 `一键启动.bat`，添加 `--server.port 8502`
3. 检查防火墙设置

### Q4: 浏览器没有自动打开

**解决**：手动打开浏览器，访问 http://localhost:8501
